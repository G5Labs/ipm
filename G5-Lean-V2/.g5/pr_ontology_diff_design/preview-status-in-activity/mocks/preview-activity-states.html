  1. Stage in the Current badge: Starting, Building, Serving on port N, Closing (Queued stays for a queued task).
  2. Ended rows: an ending verb (ended, closed, stopped, failed, did not start) plus one cause sentence in the run log's words.
  3. Run identity: the task is named with its profile at start (Preview · full-stack, or default profile); no repository name.
  4. Failure detail: a one-line cause only; the stderr tail stays in the run log.
  5. Link: no preview row opens the task's Workspace changes (always empty for a preview). Ongoing rows, failed rows whose VM may still hold output, and closes whose cleanup failed or was killed open the preview dialog with its log; every other preview row (cleanly closed, stopped, ended, never started, or lost with its VM) opens the preview dialog's launcher. The rail's Current preview row opens the same destination. Only the owner, whose ribbon carries the preview control, gets these links; readers see plain rows.
