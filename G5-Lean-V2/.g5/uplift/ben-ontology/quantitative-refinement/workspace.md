## Model-to-intent refinement

`ReviewRounds` checks seven predicates for the new D, with controls that separately break occurrence, content, decision retention, note retention, explicit clearing, distinct discussion continuity, supersession and persistent-record preservation. The model fixes one reviewer/author-kind and copy-versus-in-place partition, assumes inspected source admission and SQL publication serialization, and excludes composed child-edit reconciliation2530–2670. The source matching algorithm is abstracted, not reimplemented as proof. A repeat after lost acknowledgement creates another round. The first retry witness was rejected on inspection because a prior commit plus later abort satisfied it; it now requires historical Abort→Prepare→Commit, reached in the final retained trace.

`ReviewDiscard` checks stale preview keys, saved/observed versions, selected edits only, source isolation, truthful success and visible partial results. Each guarantee has a targeted broken control. The crash witness reaches first-file replacement, interruption, refreshed keys for the remaining second file, then completion. This is recovery by observing effects and issuing a new selection, not an undocumented request receipt/idempotency mechanism. Its atomic final version check/replacement is the intended shared file-mutation premise; the native check→rename boundary is explicitly outside its as-built claim. Platform `templates-native-race` / `NoLostWrite` independently exercises that retained shared limitation; whole-file check→delete is separately unmodeled. The report does not count this as a new independent defect.

`ReviewVerdictSync` checks complete source-vector binding, copy eligibility, Approve-only settlement, retained publication, phase-local transactions and existing-decision preservation. Source fence and full-vector controls discriminate the cut guarantee. Positive witnesses cover both an eligible nonowner request and a direct-owner requestless path; provisional authority does not imply blanket refusal. Failure recovery reenters after another push at the same reviewed cut, with no standalone retry endpoint assumed. Current read access, listed/eligible membership and fixed definitions are premises; membership/definition races, withdrawals and complete approval evidence generations remain outside this model. Both absent and invalidated requests reach the observed fallback and fail only the provisional authority predicate.

Deadlock checking is enabled; bounded completion/abandonment can quiesce. No temporal liveness claim is made for these three models because arbitrary I/O failure and user-controlled retry are unconstrained. The [manifest](https://github.com/G5Labs/G5-Lean/blob/345b546e9fed5477e6fdf3c77ad87002ed558dd6/.g5/TLA_verification/ben-quantitative/workspace/manifest.json) gives each exact predicate and case; receipts bind the read source files. Their meaningful negative outcomes occur after Init.
