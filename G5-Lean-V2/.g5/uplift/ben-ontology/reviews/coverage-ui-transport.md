# UI and browser transport: missing-intent audit

Baseline: `2d3bb3c586e0423d04bb2565a946f39602ba3f2b`, October 15, 2026.
This is a source-reading audit, with no runtime tests or model executions. Canonical
bodies, primary records and actual owners are compared separately. Proposed wording
below has not been adopted as ontology.

Add a compact security owner: runnable deployments reject known public fixture signing/verifying/encryption identities; retain deployment credentials for the lifetime of their data, and require deliberate restoration/migration when missing or corrupt. Deterministic isolated test fixtures remain allowed. No historical production compromise is asserted. |

The phase sentence's “may be gated” allows the implemented advisory BE/SE policy; it
does not prove that policy. Treat this as an incomplete commitment, not a contradiction
requiring deletion of Ben's statement. Presentation details such as chevron shape,
exact colors and ribbon spacing need no new governing block.

The audit also read all UI, documents, users, security, terminal and operations bodies.
That is ontology inspection, not corresponding whole-code coverage. Other reviewers own

implementation detail merely because they were unread.
