## Finding

### R1 — P2: Restore exact configured-token redaction at the flush error boundary

**Affected path:** `backend/g5d-dispatch/src/workspace_flush.rs:574–586`, especially the unconditional `%error` log and `error.to_string()` RPC detail. Governing commitments: `g5.security.credentials.redaction`, `g5.architecture.git_outcomes`, `g5.architecture.git_credentials`.

The old `WorkspaceFlush::git_failed` explicitly replaced `self.config.workspace_token` before logging and returned only a fixed RPC error. The replacement forwards SCM's error directly to both the log and public RPC detail. SCM knows and redacts the member relay URL; it does not possess the incarnation JWT. Its generic scrubber recognizes GitHub/GitLab credentials, URLs and private keys, but not that JWT or arbitrary configured secrets. This removes the exact-value defense and introduces a new unredacted RPC surface.

**Executed counterexample:** An isolated real `g5d dispatch` with its authenticated smart-HTTP fixture origin had a required identity filter that printed the fixture workspace JWT to stderr and failed during `git add` in flush capture. After closing admission, a real `workspace.flush` RPC returned an error containing the complete configured workspace token. The probe printed only `flush_error=true; configured_workspace_token_in_rpc=true`; no token was printed in the review output. Repository processes need not receive the token in their Git environment for this counterexample: a filter can echo an already-known configured value, which the old boundary explicitly protected. The accepted guest-token exposure does not waive public-output redaction.

**Repair:** At the dispatcher owner, redact the known incarnation/configured secret values before logging and serializing a native error. Keep the typed operation/effect information and SCM's relay redaction. Do not pass the credential into the native process or add retry state. A regression must inspect the actual RPC error and captured log when a Git filter writes a fixture-token canary, including a bounded-output prefix case. Merely testing SCM's GitHub-pattern scrubber does not discriminate this defect.

Probe: `/tmp/g5-guest-native-reviewer1/redaction_probe.rs`; successful reproduction receipt: `/tmp/g5-guest-native-reviewer1/redaction-probe.log`. The probe linked existing current-checkout artifacts and called the actual production dispatcher binary. Initial direct-link attempts required matching dependency fingerprints and adding the installed OpenSSL library directory; these were probe-build setup failures, not product failures.
