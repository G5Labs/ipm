## Initial finding

### F1 — P2: the terminal regression test assumes a Git installation the Linux test images deliberately omit

**Location:** `backend/g5d/tests/dispatch.rs:825` and `:895`.

The new test replaces the dispatcher's PATH with `/usr/bin:/bin`, then requires `command -v git` to equal `/usr/bin/git`. The repository's common Linux image installs Git under `/opt/g5-git` and links it into `/usr/local/bin` (`infra/docker/Dockerfile.base:136–151`). Its Rust/test-runner/CI descendants explicitly reject reinstalling the distribution Git package (`infra/docker/Dockerfile.test-runner:15–28`, `Dockerfile.base-rust:59–60`, `Dockerfile.ci-builder:32–33`). Thus the new test fails on the supported Linux test image before the PR command assertions, although the production launcher correctly preserves an image-supplied Git path. A local macOS pass cannot establish portability here.

**Evidence:** source inspection of the actual test, the common-image Git installation and the test/CI image inheritance. This is a source-demonstrated configuration contradiction; the current Linux CI image was not executed. A read-only check of the two locally cached guest rootfs trees found older `/usr/bin/git` installations, so those caches cannot validate the current common-image contract.

**Proposed repair:** give the test an isolated image-tool directory containing a Git fixture/forwarder, put that directory on its controlled PATH, and assert it remains the selected Git after launcher installation. Alternatively resolve the actual host Git path before restricting PATH and preserve its directory, with the expected path derived from that resolution. Keep `/opt/g5/bin` out of this image-tool PATH so the regression still detects broad bundle PATH injection.

**Regression:** run the repaired test in the current common-base Linux test runner and on macOS. The assertion must discriminate a launcher that injects/shadows Git from one that exposes only `g5d`.

No actionable production correctness or authority regression was found in the inspected incremental changes.
