# Question set fixtures (schema 3)

Shared parity corpus for `g5-contracts/src/types/question_set.rs` and
`frontend/src/lib/questionSet.ts`. Every file is generated by the Rust module's
own primitives; regenerate with

```sh
QUESTION_SET_REGEN_FIXTURES=1 cargo test -p g5-contracts --lib question_set
```

`expected.json` records each file's canonical SHA-256, per-question status and
decision flag. `non-canonical.g5q.json` is valid content in a non-canonical
layout (reversed keys, four-space indent). Set files carry no signature.
