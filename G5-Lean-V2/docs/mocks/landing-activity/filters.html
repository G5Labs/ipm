One click from All to Tasks

In Proposed, All is highlighted alone. Click Tasks to isolate it; then click Approvals to add approvals. Click a selected category to remove it, or All to reset.

Current work retains its existing exception: ongoing chats and tasks stay pinned above filtered history. Select the ongoing example to see it.

What this mock demonstrates

  • One Activity heading and its filters, followed directly by events.
  • Event titles and timestamps retain useful destinations; repeated navigation footers are removed.
  • The original issue description is summarized once in Workspace task; its opening remains a compact historical event.
  • Review replies appear once per event. Current state appears once per ongoing row.
  • All is a distinct reset state. Category clicks from All isolate; subsequent category clicks add or remove.
  • Surrounding controls are excluded from this proposal, including duplicate Start and Merge to parent actions.
