### 1.3 Product boundaries retained

One current owner writes or uses live compute. Authorized non-owners browse durable Git and persisted history and may fork into a stopped child they own. A stopped owner must explicitly Start/Resume before mutation or execution. Exact shared branch names are allocated only by the checked all-member fork service. Save never commits, pushes or boots a VM. Push sends existing commits; flush is private and accepts only `shutdown|fork`. No user Commit/Flush-now, workspace search, dedicated review-result workflow or implicit task-completion shutdown is added.

The MVP keeps the original microVM/host/credential substrate: current-owner provider key and repository/task secrets resolved at dispatch and delivered as environment; incarnation token in the guest environment; the in-guest LLM proxy; existing host JWT provisioning/renewal/rotation; selectable TSI/passt; existing Git cache/materialization and preview-origin handling. New `ctl` start/stop and API-side lease/incarnation fencing are required. No host-side lease kill timer or deployment lease guard is introduced. GitHub/GitLab publication credentials remain server-side.
