## Scoring, fixed before outputs

Preserve the earlier subjective ontology judgment of 7.5/10. It used intent 35% (9),
conditions/exceptions 30% (6), architecture/compatibility/verification 15% (7), scope
precision 10% (9), and detailed repeatability 10% (6). These were qualitative judgments,
not calibrated probabilities or fractions of broad reference groups.

Code has one run per scenario: repeatability is **unmeasured**. Do not invent a value.
Compare both packages on the first four dimensions, renormalized to 90%:

`(35 × intent + 30 × conditions + 15 × architecture + 10 × precision) / 90`

The retained ontology scores produce 7.67, displayed as **7.7/10** on this comparable
scale. Score each code scenario on the same dimensions, with evidence; use their equal
mean for an aggregate. Keep the original 7.5 and the new comparable 7.7 clearly separate.
No repeated-run probability, significance or full five-dimension code score is claimed.

Qualitative anchors: 0 = no useful correct obligations; 3 = fragmentary with major gaps;
5 = useful outline with substantial material gaps; 7 = strong working inventory with
material omissions; 9 = nearly complete material coverage with minor gaps; 10 = no
material gap established within this observed sample. Intermediate half-points allowed.
Judge severity and applicability, not word count, ID citation or a percentage of groups.
Scope precision scores restraint/faithfulness, not recall. Full-target recoverability can
be lower because an input lacks intended decisions; explain this separately from agent error.

Evaluation is not fully blinded: input type is evident, the reference is ontology-derived,
and the parent knows previous results. Independent graders do not receive the old numerical
scores until after their assessments are saved. Original judgments and parent corrections
remain separate. The reference cannot establish every legitimate code-derived obligation.
