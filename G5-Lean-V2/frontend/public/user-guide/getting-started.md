# Getting started

G5 work happens in a workspace through conversations and tasks.

1. Open a project and fork a workspace for your change.
2. Create or open the relevant project documents, then describe the work in Chat. Sync and other guided actions start conversations with the relevant context.
3. Follow the conversation and the task status in **Tasks**. Load older history when needed; a direct task link opens even when its history page has not loaded.
4. Review the workspace changes and run the relevant checks. Use Preview when the application offers one.
5. Commit your changes, then use the workspace's merge or pull request action to publish the reviewed result.

Independent conversations share the workspace. Fork another workspace when you need isolated changes.

See the [current walkthrough](getting-started-latest.md) for more detail.
