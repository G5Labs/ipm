# 05 — Uninstall, Clean and orphans

Module root: UNIN-0

Scope: `uninstall` (single, `-r`, `-force`, `-all`, `-global`, `-purge`, IPM removing itself), the Clean phase run as
`<module> clean`, `orphans`, what is deleted and what is kept, dependents that block removal, and the lack of an
undo for uninstall. History-log fields (what a log entry records, `Committed`) belong to module 02; this module only
says when an uninstall writes a log entry. Baseline: ipm 571e04a1. Paths below are relative to the IPM checkout
(`ipm/`). `X` tags name tests that assert the claim but were not run here. `O` and `T` tags come from native runs on
IRIS 2026.1 in container `ipm-uplift-iris-repo` (logs `validation/logs/7*-repo-*.log`; check table in
`intents/05-06-seed-challenge.md`).
`P` tags name lemmas of `models/verus/uninstall.rs` (verified, controls all killed); `M` tags name checks of
`models/explorer/repo/check.py` in `evidence/model-checks-repo.json`. Premises are named in each Note and in
`models/verus/uninstall.TRUST.md`. `O!` marks an observation that refutes its statement (always with F or OPEN). A
statement with F carries no P: a proof under a premise that excludes the statement's case is not evidence for it, and
a defect witness is cited in the finding.
