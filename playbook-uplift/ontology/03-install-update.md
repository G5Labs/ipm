# 03 — Install, reinstall and update

Module root: INST-0

Scope: the `install`, `reinstall` and `update` commands; the install-versus-update guard; ordered update steps; mirrors;
platform filtering; registry selection. Dependency resolution itself is in `04-dependencies.md`. Baseline: ipm
571e04a1. Paths in Source are relative to the IPM checkout (`ipm/`). An `X` tag means a test asserts it, not that it
holds here. `O:nc-inst-*` and `O:nc-dep-*` tags come from the native checks in `intents/03-04-seed-challenge.md`
("Native check results"), and `T` tags from IPM tests run here (`validation/logs/64-inst-ipm-tests.log`), all on
IRIS 2026.1.
