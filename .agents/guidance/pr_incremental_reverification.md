# PR incremental re-verification

Honor an explicit backend choice in the request. Otherwise read each repository's declared foundation and governing instructions, defaulting to TLC. Follow [Verus incremental re-verification](Verus/incremental-reverification.md) for Verus or [TLA+ / TLC incremental re-verification](TLC/pr_incremental_TLA_reverification.md) for TLC. Do not mix the two backends within a repository; report competing foundations instead of choosing one silently.
