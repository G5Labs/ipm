# formats · iter47

YAML file and device: descriptions as "|" block scalars read back by PyYAML with a trailing newline and without first-line leading spaces; a raw CR does not reach the file. Counts from the shared summary. Native jsonf/yamlf/yamld keys. CR facts from file exports only.

- YAML file and device: descriptions as "|" block scalars read back by PyYAML with a trailing newline and without first-line leading spaces; a raw CR does not reach the file. Counts from the shared summary. Native jsonf/yamlf/yamld keys. CR facts from file exports only.
- TOON: every text field RFC 4180-quoted and read back exactly except that a raw CR is dropped; a method with a thrown error and no assertions gets an error row and a status row; declared row count equals emitted rows. Native toonf/toond keys.
- Reference: JSON file keeps every message exactly (CR escaped as text); all three device summaries print the same method counts from GetSummary. JUnit XML only checked for presence.
