# Iteration 2 trust boundary

These files contain Verus state and contract translations of pinned IPM decisions. No ObjectScript method body is mechanically verified. There are no admitted proof bodies or axiomatic assumptions. Native observations and source inspection validate only named projections; an integer or Boolean input at a port is not a proof that a provider supplies it.

`registry.rs` permits arbitrary tag sequences and manifest layer sequences. Tag integers preserve identity and order, not semantic-version arithmetic. Layer decoding preserves tar-media classification, size and digest equality. HTTP parsing, lowercasing, challenge parsing, credentials attachment, actual hash calculation, XML content, provider tag enumeration and filename selection remain explicit boundaries. Remote writes and returned status are independent inputs, allowing partial effects on failure. Prefix effects require a completed-call count between zero and the supplied tag-list length; they do not prove actual registry atomicity, validation or concurrent behavior. Cache flags represent a retained manager instance, with no lifetime claim across shell calls. `version_assigned_in_memory` is not a persisted version result.

`readers.rs` represents unscoped selection, installed-status categories, trimmed-line selection, status-based method/assertion counts, output section selection, a successful-setup verify plan, raw test-prefix selection and one eligible uninstall traversal step. SQL ordering, string decoding, semver Satisfies, real serialization, IO failure/partial bytes, actual verification namespace cleanup, every test executed and aggregate uninstall progress are not proved. The provider's retained store after failed uninstall is independent of error status. Case error means the derived nonempty case.error field, not every failed case status.

The native fixture exercises actual compiled IRIS source with a loopback registry and separately reads final report, environment and configuration values. It does not establish all external boundaries above. Boundary state/ports, finite schedules and native restart premises have their own [TRUST.md](boundaries/TRUST.md).

Source/model mapping was independently reviewed in the inventory lane. Accepted member counts are a union of narrow projections, not whole-member proofs or independent quality gains. Shared duplicated manager contracts and helper counts must not be summed as discoveries. Human priorities, disputed policy and human comprehension remain unmeasured.
