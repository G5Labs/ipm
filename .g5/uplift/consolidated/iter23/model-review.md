## Reused and new contracts

`inherited_history` imports unchanged `consolidated/verus/history.rs`. The new `finalize` calls its finalization rule, and `render` calls its `success_to_string` rule. Its integer statuses are symbolic classification tags; tag 2 is not a claim that an encoded native failure equals the integer 2. The old raw-versus-summary neighbors remain valid. This lane adds actual byte values, library annotation ports, ordered cleanup, color configuration, styling, strict UTF-8 observation, and independently captured field-slice comparisons.

`Status.raw` is the selected stored Success value. `error_text` and `is_ok` annotate that value through the SDK provider; they are neither extra stored columns nor a supplied final renderer answer. `Record.projection` carries the inherited metadata projection. Finalization copies the selected raw bytes; successful persistence copies that value and sets Finalized. These are conditional successful reload/save/twin-availability contracts, not a proof of IRIS persistence or the complete install path. The dummy ID, namespace, package and other initial fields do not stand for the actual native record identity or all its columns. Native row IDs remain opaque and are selected independently by the driver.

`render` derives detail/raw and summary/Success-or-decoded behavior through the reused reader. Active `clean` follows the source's three ordered replacement passes: CR, LF, TAB. `clean_from` is a retained one-pass prototype with no generic equivalence theorem or active caller credit. `detail_line` models only the Success line, excluding its terminating device newline. `summary_value` excludes the row's separator space; `summary_field` includes it. `configured_detail` and `configured_summary` derive their color Boolean from compiled-settings-class presence and returned setting bytes unequal to `none`. Settings storage/GetValue remains a provider port. The measured enabled setting is empty, so this is a meaningful neighbor to `none` and class absence.

The formatting macros are auxiliary source ranges, not invented named census members. Dim is ESC[2m, Default ESC[39m, and reset ESC[0m; nested control-label formatting and outer wrappers are modeled literally. Raw bytes can themselves contain ESC or NUL; the model does not promise generic ANSI stripping, terminal state, or text sanitization. Strict UTF-8 validation is an observation predicate with neighbors for isolated continuation bytes, overlong sequences, surrogates, out-of-range scalars, and truncated sequences. It is not an encoding guarantee supplied by the product.
